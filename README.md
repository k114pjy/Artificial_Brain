# DA 1년 트랙

빅데이터사이언스 학습을 위한 초기 웹 프로토타입입니다. 개념 지도와 실무 문제의 두 경로를 제공합니다.

## 실행

프로젝트 폴더에서 다음을 실행합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 별도 패키지 설치는 필요하지 않습니다. 마지막 학습 위치와 직접 표시한 복습 개념은 해당 브라우저의 로컬 저장소에 저장됩니다.

## 현재 상태

개념 탐색·검색, 관련 개념 이동, 세 가지 예시 문제, 로드맵, 수동 복습 표시와 정적 이해도 확인을 제공합니다. 콘텐츠는 초기 예시이며 전체 1년 분량은 아직 제공하지 않습니다. 링크는 참고 자료이며 구체적 사례에 대한 출처 검토와 본문 확장이 필요합니다.

AI 대화와 대화 기반 자동 복습, 최신 시사 추천, 사용자 계정과 기기 간 동기화, 노션 자동 저장은 아직 구현되지 않았습니다. 사용자의 데이터를 서버에 저장하지 않습니다. 브라우저 저장소를 지우면 로컬 기록도 사라집니다.

## 3D 개념 지도

FreeSurfer fsaverage5 대뇌 표면에서 추출한 외곽 윤곽과 내부 연결망을 Three.js/WebGL로 렌더링합니다.
주름을 채운 표면 대신, 부드러운 윤곽 안에 입체적으로 분산된 점과 연결선을 표시합니다.
드래그/터치로 회전하고 휠/두 손가락으로 확대합니다. 개념은 작은 점으로
배치되며 이름은 선택하거나 가리킬 때 표시됩니다. 소뇌와 뇌간은 형태를
보완하기 위한 별도 도형입니다. 데이터 출처와 배포 조건은
[assets/ATTRIBUTION.md](assets/ATTRIBUTION.md)를 참조하세요.

Three.js 0.180.0은 `vendor/`에 포함되어 외부 CDN 연결 없이 작동합니다.
WebGL이 지원되지 않으면 안내와 개념 선택 목록을 제공합니다.

브라우저 검증: Playwright가 설치된 환경에서 위 로컬 서버를 실행한 뒤
`node tests/brain3d.cjs`를 실행합니다. Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다.
