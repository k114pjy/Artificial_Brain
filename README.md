# DA 1년 트랙

빅데이터사이언스 학습을 위한 초기 웹 프로토타입입니다. 개념 지도와 실무 문제의 두 경로를 제공합니다.

## 실행

프로젝트 폴더에서 다음을 실행합니다.

```bash
python server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 별도 패키지 설치는 필요하지 않습니다. 마지막 학습 위치와 직접 표시한 복습 개념은 해당 브라우저의 로컬 저장소에 저장됩니다.

## 현재 상태

개념 탐색·검색, 관련 개념 이동, 세 가지 예시 문제, 로드맵, 수동 복습 표시와 정적 이해도 확인을 제공합니다. 콘텐츠는 초기 예시이며 전체 1년 분량은 아직 제공하지 않습니다. 링크는 참고 자료이며 구체적 사례에 대한 출처 검토와 본문 확장이 필요합니다.

1년 12단계 목차와 각 단계의 핵심 학습 예제를 제공합니다. 가상 데이터와 Iris 공개 데이터를 활용하며, 12단계 목차의 모든 세부 강의와 단계별 실제 데이터 프로젝트는 아직 완성되지 않았습니다. 실무 문제는 세 가지 가상 예제로, 선수 개념을 본 뒤 이전 단계로 돌아올 수 있습니다.

AI 튜터는 로컬 서버의 `/api/tutor`를 통해 OpenAI Responses API에 요청합니다. `.env.local`의 `OPENAI_API_KEY`는 서버에서만 읽으며 Git에서 제외합니다. API 크레딧과 모델 접근 권한이 있어야 응답합니다. 오류가 나면 튜터 화면에 표시합니다. GitHub Pages에는 서버가 없으므로 별도의 서버 배포 전까지 AI는 공개 사이트에서 연결되지 않습니다. 대화 원문은 브라우저의 로컬 저장소에 저장됩니다.

대화 기반 자동 복습과 노션 자동 저장의 로컬 구현은 추가되었지만 실제 AI 응답과 노션 연결을 통한 검증은 각각 API 크레딧 충전과 노션 통합 설정 후 필요합니다. 계정과 기기 간 동기화는 아직 구현되지 않았습니다. 브라우저 저장소를 지우면 로컬 기록도 사라집니다. 음성 입력·출력은 브라우저의 해당 기능과 마이크 권한이 있을 때만 사용할 수 있습니다.

## 노션 연결

Codex의 노션 연결과 웹사이트의 서버 연결은 별개입니다. [노션 API 시작 안내](https://developers.notion.com/guides/notion-api/quick-start)를 참고해 토큰을 준비하세요. 내부 통합을 사용하는 경우 학습 기록 상위 페이지의 연결 메뉴에서 그 통합에 페이지 접근 권한을 부여합니다. 로컬 `.env.local`에 `NOTION_TOKEN`과 상위 페이지의 `NOTION_PARENT_PAGE_ID`를 설정하고 서버를 다시 시작하세요. 값은 채팅이나 GitHub에 올리지 마세요. 필요한 변수 이름은 `.env.example`에 있습니다.

설정 후 사이트 하단의 저장 상태를 확인할 수 있습니다. 개념 요약·출처, 문제 단계와 코드, 질문과 AI 답변 요약이 날짜별 페이지의 세 영역에 기록됩니다. 연결 전 기록은 이 브라우저에 대기하며, 재시도하거나 지울 수 있습니다. 네트워크 오류가 저장 성공 직후 발생하면 재시도할 때 중복이 생길 수 있습니다. 실제 노션 토큰으로 아직 통합 검증하지 않았습니다.

공개 운영에는 인증된 별도 서버와 사용자별 데이터 저장소가 필요합니다. `server.py`는 로컬 컴퓨터에서만 접근하도록 만들어졌고 공개 운영용 인증·요금 제한·여러 사용자 분리를 제공하지 않습니다. [설계 초안](docs/ARCHITECTURE.md)을 참고하세요.

## 개념 지도

흰 배경에 작은 점과 SVG 곡선을 배치한 퍼셉트론 스타일 지도입니다.
기초 개념 · 핵심 원리 · 응용의 세 단계로 구성하며, 선택한 개념과
직접 연결된 개념·경로만 크림슨색으로 표시합니다. 선은 학습을 위한
개념 간 관계이며 실행 순서나 인과관계를 뜻하지 않습니다.

점을 클릭하거나 키보드로 선택하면 설명, 활용, 연결 이유, 참고 자료를
확인할 수 있습니다. 검색은 한글·영문 개념명과 분류를 지원합니다.
기존 `#map/<id>` 주소와 `da-last`, `da-review` 로컬 저장 기록은 유지합니다.

모바일에서는 지도 안에서 좌우로 스크롤하거나 「개념 바로 선택」을 사용합니다.
설명은 지도 아래에 표시되며 「설명 보기」로 바로 이동할 수 있습니다.
3D 렌더러와 WebGL, Three.js, 뇌 모델 다운로드는 사용하지 않습니다.

## 검증과 배포

Node.js 22 이상에서 `node --test tests/concept-map.test.mjs tests/core-lessons.test.mjs`로 기존 개념 ID,
연결 관계, 선택 강조, 세 단계의 배치와 학습 링크를 검증합니다.
`python -m unittest discover -s tests -p 'test_*.py'`는 서버 보안과 모의 노션 요청을 검증합니다.
NumPy·pandas·Matplotlib이 설치되어 있다면 `python tests/check_lessons.py --real`로 핵심 가상 예제와 실제 Iris 프로젝트를 실행할 수 있습니다. `--real`에는 인터넷이 필요합니다.
정적 사이트이므로 별도 빌드는 필요하지 않습니다.

브라우저 확인 항목: 데스크톱·모바일의 개념 선택과 관련 개념 이동,
한글·영문 검색, Enter/Escape, 복습 표시·해제와 새로고침 후 유지,
실무 문제·이해도 확인·로드맵·학습 이어하기, 페이지 가로 넘침과 콘솔 오류.
