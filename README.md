# DA 1년 트랙

빅데이터사이언스 학습을 위한 초기 웹 프로토타입입니다. 개념 지도와 실무 문제의 두 경로를 제공합니다.

## 실행

프로젝트 폴더에서 다음을 실행합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 별도 패키지 설치는 필요하지 않습니다. 마지막 학습 위치와 직접 표시한 복습 개념은 해당 브라우저의 로컬 저장소에 저장됩니다.

## 현재 상태

개념 탐색·검색, 관련 개념 이동, 세 가지 예시 문제, 로드맵, 수동 복습 표시와 정적 이해도 확인을 제공합니다. 콘텐츠는 초기 예시이며 전체 1년 분량은 아직 제공하지 않습니다. 링크는 참고 자료이며 구체적 사례에 대한 출처 검토와 본문 확장이 필요합니다.

AI 대화와 대화 기반 자동 복습, 최신 시사 추천, 사용자 계정과 기기 간 동기화, 노션 자동 저장은 아직 구현되지 않았습니다. 사용자의 데이터를 서버에 저장하지 않습니다. 브라우저 저장소를 지우면 로컬 기록도 사라집니다.

## 개념 지도

흰 배경에 작은 점과 SVG 곡선을 배치한 퍼셉트론 스타일 지도입니다.
기초 개념 · 핵심 원리 · 응용의 세 단계로 구성하며, 선택한 개념과
직접 연결된 개념·경로만 크림슨색으로 표시합니다. 선은 학습을 위한
개념 간 관계이며 실행 순서나 인과관계를 뜻하지 않습니다.

점을 클릭하거나 키보드로 선택하면 설명, 활용, 연결 이유, 참고 자료를
확인할 수 있습니다. 검색은 한글·영문 개념명과 분류를 지원합니다.
기존 `#map/<id>` 주소와 `da-last`, `da-review` 로컬 저장 기록은 유지합니다.

모바일에서는 지도 안에서 좌우로 스크롤하거나 「개념 바로 선택」을 사용합니다.
설명은 지도 아래에 표시되며 「설명 보기」로 바로 이동할 수 있습니다.
3D 렌더러와 WebGL, Three.js, 뇌 모델 다운로드는 사용하지 않습니다.

## 검증과 배포

Node.js 22 이상에서 `node --test tests/concept-map.test.mjs`로 기존 개념 ID,
연결 관계, 선택 강조, 세 단계의 배치와 키보드 탐색용 링크를 검증합니다.
정적 사이트이므로 별도 빌드는 필요하지 않습니다.

브라우저 확인 항목: 데스크톱·모바일의 개념 선택과 관련 개념 이동,
한글·영문 검색, Enter/Escape, 복습 표시·해제와 새로고침 후 유지,
실무 문제·이해도 확인·로드맵·학습 이어하기, 페이지 가로 넘침과 콘솔 오류.

GitHub Pages는 `main` 브랜치의 루트 정적 파일을 게시합니다.
