# 여러 기기와 공개 서비스 설계 초안

현재 구현은 로컬 서버와 브라우저 저장소를 사용한다. 여러 기기 동기화와 공개 서버는 아직 구현되지 않았다.

1. 신뢰할 수 있는 인증 제공자를 이용해 사용자별 세션을 발급하고, 모든 기록 요청에서 사용자 ID를 서버가 검증한다. API 키와 노션 토큰은 서버의 비밀 저장소에만 둔다.
2. 학습 위치, 대화 원문, 복습 개념과 수정된 이유를 사용자별 데이터베이스에 저장한다. 항목 ID, 수정 시각, 버전 번호, 삭제 표시를 두어 재접속과 충돌을 처리한다. 기기마다 별도 브라우저 기록이 있는 현재 상태를 동기화된 것처럼 표현하지 않는다.
3. 노션 기록은 사용자별 연결 및 지정한 상위 페이지를 통해 비동기 작업으로 보낸다. 이벤트마다 안정적인 ID를 부여하고, 실패 재시도와 중복 방지를 영속 저장한다. 동기화 상태와 실패 이유를 사용자에게 표시한다.
4. 서버는 소유자 검증, 요청 크기 제한, 사용자별 사용량 제한, 데이터 보존·삭제 기능을 제공한다. 로그에 비밀 키, 대화 원문 또는 토큰을 남기지 않는다. 노션 연결을 해제하면 이후 전송을 중지한다.
5. 실제 배포 전 여러 계정의 접근 격리, 동시 편집, 오프라인 복구, 노션 권한 거절, 중복 전송, API 사용 한도와 음성 권한을 검증한다. GitHub Pages는 정적 화면만 호스팅하므로 서버와 데이터베이스는 별도로 배포해야 한다.
